# 💊 Sistema de Gerenciamento de Estoque para Farmácia

Projeto desenvolvido em grupo durante o curso de **Programador de Sistemas do SENAC RN**, com o objetivo de facilitar o controle de produtos e a organização do estoque de uma farmácia. A aplicação apresenta uma interface simples, moderna e responsiva, permitindo visualizar medicamentos, cadastrar produtos, acompanhar quantidades disponíveis, realizar reposições e montar um carrinho.


## 🎓 Sobre o projeto

Este trabalho foi produzido de forma colaborativa como parte das atividades do curso de **Programador de Sistemas**, oferecido pelo **Serviço Nacional de Aprendizagem Comercial do Rio Grande do Norte — SENAC RN**.

O projeto permitiu ao grupo aplicar conhecimentos de desenvolvimento web, criação de interfaces e organização de sistemas em uma solução voltada para o gerenciamento de estoque farmacêutico.


## ✨ Funcionalidades

- Tela de login para acesso da farmácia;
- Visualização dos produtos cadastrados;
- Cadastro de produtos com nome, valor, quantidade e imagem;
- Indicação visual para produtos sem estoque;
- Reposição da quantidade disponível;
- Confirmação antes de adicionar novos itens ao estoque;
- Montagem e visualização do carrinho;
- Interface organizada e adaptável a diferentes tamanhos de tela.

## 🖥️ Telas do sistema

### Login

Tela inicial para identificação e acesso da farmácia.

### Produtos

Exibe os medicamentos cadastrados, seus preços e as quantidades disponíveis.

### Cadastro de produto

Formulário para inserir as informações de um novo produto no estoque.

### Reposição de estoque

Permite aumentar a quantidade de um produto já cadastrado, com uma etapa adicional de confirmação.

### Carrinho

Apresenta os produtos selecionados e o resumo do pedido.
